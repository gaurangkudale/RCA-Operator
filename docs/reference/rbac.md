# RBAC Reference

The operator follows least-privilege principles. It only requests the permissions it strictly needs.

---

## ClusterRole — rca-operator-manager-role

Generated by `make manifests` from `// +kubebuilder:rbac:` markers in the controller source. Do **not** edit `config/rbac/role.yaml` by hand.

### Current Permissions

| API Group | Resources | Verbs | Purpose |
|---|---|---|---|
| `""` (core), `events.k8s.io` | `events` | get, list, watch, create, patch | Emit Kubernetes events on IncidentReport CRs and read events for signal collection |
| `""` (core) | `namespaces` | get, list, watch | Validate `watchNamespaces`, list workload namespaces |
| `""` (core) | `nodes` | get, list, watch | Node signal collection (NodeNotReady, taints) |
| `""` (core) | `pods` | get, list, watch | Pod signal collection and ownership resolution |
| `""` (core) | `pods/log` | get | Stream pod logs to the dashboard Logs tab |
| `""` (core) | `secrets` | get, list, watch | Validate Slack and PagerDuty notification secrets |
| `""` (core) | `services` | get, list, watch | Service topology graph (`/api/service-graph`) and resource detail panel |
| `apps` | `deployments` | get, list, watch | Deployment watcher for stalled rollout detection |
| `apps` | `statefulsets` | get, list, watch | StatefulSet watcher for stalled rollout detection |
| `apps` | `daemonsets` | get, list, watch | DaemonSet watcher for stalled rollout detection |
| `apps` | `replicasets` | get, list, watch | Ownership resolution (Pod → ReplicaSet → Deployment) |
| `batch` | `jobs` | get, list, watch | Job watcher for failed job detection |
| `batch` | `cronjobs` | get, list, watch | CronJob watcher for failed child job detection |
| `rca.rca-operator.tech` | `incidentreports`, `rcaagents` | get, list, watch, create, update, patch, delete | Create and manage incidents and agents |
| `rca.rca-operator.tech` | `incidentreports/status`, `rcaagents/status` | get, update, patch | Write status and phase transitions |
| `rca.rca-operator.tech` | `incidentreports/finalizers`, `rcaagents/finalizers` | update | Manage cleanup finalizers |
| `rca.rca-operator.tech` | `rcacorrelationrules` | get, list, watch, create, update, delete | Load correlation rules; auto-detection creates/updates/deletes rules |
| `rca.rca-operator.tech` | `rcacorrelationrules/status` | get | Read rule status |

The authoritative source is `config/rbac/role.yaml` (regenerated from kubebuilder markers). Run `make manifests` after editing any `// +kubebuilder:rbac:` marker.

### Leader Election Role (separate)

## ServiceAccount

The operator runs as `rca-operator-controller-manager` in the `rca-system` namespace.

```bash
kubectl get serviceaccount -n rca-system
kubectl get clusterrolebinding | grep rca-operator
```

---

## Viewing the Live Role

```bash
# See what the operator is currently allowed to do
kubectl get clusterrole rca-operator-manager-role -o yaml
```
